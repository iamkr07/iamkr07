## Featured Projects

### 🔍 RING//BREAK

Financial fraud ring detection and multi-agent forensic platform. Pairs a **Graph Attention Network** with an autonomous four-agent investigation pipeline to surface circular laundering loops, fan-in layering, and repeat-offender networks.

- 2-layer GAT with learned edge attention weights to highlight suspicious transaction corridors
- Built on the AMLSim dataset: 117,000+ transaction edges, 1,000 account nodes, 40 alert clusters
- Sequential agent pipeline: Detection → Topology → Risk Assessment (0–100 score) → Countermeasure Simulation
- Investigator authentication, tab-switch lock screen, and Trace ID-protected AES-encrypted PDF reports
- Pre-indexed adjacency tables for O(1) neighbor lookups across the transaction graph

**Live:** <https://ringbreak-fraud-detection-pu6ys9sic-cse271025-sudos-projects.vercel.app/>

`Python` `FastAPI` `PyTorch` `PyTorch Geometric` `React` `TypeScript` `Tailwind CSS`
